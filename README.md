## How to Compile and Run

### Requirements

* GCC compiler
* Command Prompt or terminal
* A text editor or IDE, such as VS Code

### Steps

1. Clone or download this repository.

2. Open the program folder in Command Prompt.

3. Compile a C program:

   ```bash
   gcc program1.c -o program1
   ```

4. Run the program on Windows:

   ```bash
   program1.exe
   ```

   Replace `program1.c` with the filename of the program you want to compile.
